Project 01 — Main

01 / 03

RentMyCar

Peer-to-peer car rental platform — owners list vehicles, users search and book them

● Live In Progress Full-stack

What's built

  • Auth system — sign-up, sign-in, forgot-password; JWT tokens via NextAuth.js, bcrypt password hashing, route protection through Next.js middleware
  • Car listings — add a car with 7 enumerated fields (make, type, engine, city, registration, mileage, consumption) and multi-image upload
  • Image pipeline — uploaded images processed server-side with Sharp (resized to 800×600, JPEG compressed), stored as base64 in MongoDB
  • Search & filter — filter by make, type, engine, city, price range; results paginated with page / limit / totalPages response
  • Availability logic — 3-case MongoDB overlap query excludes already-booked cars from results in real time
  • Booking system — date range picker, total cost calculated server-side (days × pricePerDay), saved to DB with car/user references
  • Owner dashboard — view own listings, update car via modal, paginated rental history
  • PWA — Service Worker at /sw.js, installable on mobile as native-like app
  • Responsive — separate desktop and mobile component sets for best UX on both
  • Analytics — Vercel Analytics + Speed Insights integrated

Technical highlights

  • Next.js App Router — file-based routing, server components, API routes all in one project
  • Mongoose schemas with enum validation, populate() joins, and connection caching pattern for serverless (prevents connection pool exhaustion on Vercel)
  • MongoDB overlap query — handles 3 rental conflict cases: start inside, end inside, and full overlap
  • Zod validation on all API inputs — type-safe request parsing
  • NextAuth CredentialsProvider — custom sign-in flow with MongoDB lookup and bcrypt.compare
  • Sharp image processing — server-side compression with dynamic import (avoids edge runtime issues)
  • React Hook Form + Zod resolvers for all client-side forms
  • Radix UI primitives — accessible Select, Checkbox, Popover, RadioGroup, Label components
  • Mobile detection — CSR utility + useMediaQuery hook for adaptive rendering
  • TypeScript throughout — strict types, interfaces for all models and API responses

Unfinished React 18

What was built

Technical highlights
